# Guiraos Usinagem & Ferramentaria

Landing page desenvolvida para a Guiraos Usinagem & Ferramentaria, empresa 
especializada em serviços de usinagem, localizada em Santa Bárbara d'Oeste - SP.

## Sobre o projeto

Site institucional em página única (one-page), com seções de apresentação, 
serviços oferecidos, contato direto via WhatsApp e localização integrada 
com Google Maps.

## Funcionalidades

- Design responsivo com efeito de fundo animado
- Menu de navegação com rolagem suave até cada seção
- Contato direto via WhatsApp (link `wa.me`) e e-mail
- Localização incorporada via Google Maps
- Cards de serviços com efeito hover

## Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, animações, design responsivo)
